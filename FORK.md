## Справочник апстрима (не зависимость)

Мержей нет, но клон апстрима с полной историей и тегами лежит рядом:
`/opt/korra-2.0/repo` и `/opt/korra-fresh` (remote `upstream`, тег `v2026.8.31`).

Он нужен для одного: когда внешний мир что-то ломает — провайдер меняет схему
авторизации, мессенджер меняет API, приходит CVE, — посмотреть, как это починили
там, и перенести руками. Прецеденты у нас были: OpenAI начал слать `output=None`
и положил флот; у xAI умер loopback-PKCE. Это не фичи, это поддержание света,
и после жёсткого форка оно наше.

## Правило, ради которого всё затевалось

Каждое изменение — коммит с внятным сообщением. Прошлый форк стал нечитаемым
именно потому, что дельта копилась без записи: её пришлось восстанавливать
замерами. Здесь дельта = история, начиная с первого коммита.

## Права на чекаут — держатся ACL, а не chown

Агент внутри контейнера работает под uid 10000 и должен уметь править этот
чекаут и коммитить. Одного `chown` мало: любая git-операция с хоста от root
(`checkout`, `reset`, смена ветки) **пересоздаёт файл** и возвращает ему
root-владельца — агент молча теряет запись. Поэтому стоят ACL, включая
default-ACL, который наследуют новые файлы:

```
setfacl -R -m  u:10000:rwX /opt/korra-21
setfacl -R -d -m u:10000:rwX /opt/korra-21
```

Хостовой git при этом требует `git config --global --add safe.directory /opt/korra-21`.
