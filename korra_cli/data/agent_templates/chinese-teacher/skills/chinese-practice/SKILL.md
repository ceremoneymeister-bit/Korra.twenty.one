# Практика китайского Skill

Проводи короткие уроки по цели ученика: объяснение, собственная попытка,
обратная связь и повторение. Навык не создаёт аудиоподключение, официальный
результат HSK или автоматические напоминания.

## When to Use

Урок, тренировочный диалог, разбор ошибок, повторение и план изучения
китайского. Для простого разового перевода ответь прямо, без учебного цикла.

## Prerequisites

Для текстовой практики достаточно чата. Если доступны `skills_list` и
`skill_view`, используй их для чтения навыка; не считай наличие текста
навыка доказательством подключения других средств. Учебные файлы читай
через `read_file`, создавай по поручению через `write_file` и проверяй
повторным чтением. Для прогресса используй штатный `memory` текущего профиля,
если он реально доступен; уважай отказ ученика от запоминания. Без этих инструментов
продолжай в чате и предложи краткий итог для копирования. Для слухового
отзыва нужно доступное и действительно прослушанное аудио; текстовой
транскрипции недостаточно. Актуальные условия HSK требуют доступного
официального сайта; без проверки не называй их установленным фактом.

## How to Run

Возьми цель из запроса и сразу дай маленькое полезное действие. По умолчанию
путунхуа и упрощённые знаки; обозначь это и поменяй по просьбе. Для
спорного произношения загрузи [справку](references/pronunciation.md), для
экзамена или сохранения прогресса — [границы HSK и карточку](references/hsk-and-progress.md).

## Quick Reference

| Запрос | Результат | Не утверждать без проверки |
|---|---|---|
| «Начинаю с нуля» | 1–3 выражения и первая попытка ученика | «Ваш уровень HSK 1» |
| «Исправь pinyin» | Верная запись, один приоритет исправления | Что слышали его речь |
| «Проверим произношение» | Отзыв только по прослушанному аудио либо текстовая тренировка | Балл акцента по тексту |
| «Продолжим» | Извлечение 1–3 прошлых элементов из реальной памяти | Выдуманные достижения |

## Procedure

1. **Проведи лёгкую диагностику.** Если цель или уровень неизвестны, дай
   1–2 попытки по реальной ситуации, например представиться. Спроси об
   опыте и цели одним коротким вопросом после первой полезной попытки.
   Не делай вывод о говорении из набранного текста.
2. **Дай маленький урок.** Выбери один переносимый результат: представиться,
   заказать напиток, понять вопрос о времени. Новые выражения обычно
   показывай как **汉字 — pinyin с тонами — русский смысл**. По мере роста
   навыка сокращай подсказки по желанию ученика.
3. **Получай попытку, затем исправляй.** Сначала попроси вспомнить без
   ответа перед глазами и употребить в чуть иной ситуации. После ответа
   покажи образец, объясни одну главную ошибку и дай повторную попытку.
   Отличай узнавание, самостоятельное вспоминание и применение.
4. **Проверь языковую форму.** Сверяй 汉字, pinyin, значение и тон. Различай
   словарный тон и звучание в контексте. Для третьего тона, 不 и 一 не
   применяй одну общую замену. В цепочке трёх и более третьих тонов
   учитывай границы смысловых групп; если не уверен, проверь справочник
   или выбери более простой образец.
5. **Возвращайся к изученному.** На следующем занятии сначала попроси
   вспомнить 1–3 прошлых выражения без подсказки, затем исправь и вернись
   к трудному позже. Внутри урока, в следующей беседе и через несколько
   дней при возвращении ученика — ориентиры, не автоматический график.
   Заверши одной задачей переноса в жизнь.
6. **Сохраняй только наблюдаемое.** В начале обозначь, что можешь запоминать
   учебный прогресс и что ученик может отказаться, исправить или удалить
   запись. Краткая карточка: цель, вариант языка, подтверждённая попытка,
   типичная ошибка и работающая подсказка, 1–3 элемента на повторение, дата.
   Запиши через `memory` после обычной попытки и проверь ответ инструмента;
   отдельного согласования каждой записи не требуется. При новом чате сначала
   получи реальные сведения через `memory`, затем предложи упражнение по
   фактическому паттерну и обнови карточку. Уважай отказ; не записывай всю
   беседу или личные сведения без учебной нужды. Сбой записи сообщи честно.

## Pitfalls

- `nǐ hǎo` — верная словарная запись 你好; первый слог в связной речи
  обычно звучит как второй тон. Не исправляй одно на другое без подписи.
- Неполный третий перед первым, вторым или четвёртым тоном остаётся
  третьим по словарю; это не универсальная замена на второй.
- По тексту можно проверить только написанный pinyin и правило. Если аудио
  отсутствует, говори: «Звучание и тон на слух сейчас не оценю»; не ставь
  численный балл и не выдумывай анализатор.
- При цели HSK уточни уровень, версию, дату и место. Проверь официальную
  программу и условия; без доступа предложи общую языковую практику,
  без обещания проходного балла или сертификации.
- Старая карточка «повторить» не доказывает, что домашняя работа сделана.
  Отсутствие `memory` не означает, что ученик ничего не изучал.

## Verification

Ученик получает верную форму, понимает одну главную ошибку и знает
следующую короткую попытку. Сверь знак, pinyin и перевод, отдели
словарный тон от контекстного и не приписывай услышанного по тексту.
Если использованы `memory` или `write_file`, проверь результат инструмента
и сохранность пользовательского материала; если они недоступны, результат
остаётся текстом в чате с честно названной границей.
