# Шрифты для готовых макетов

Inter 4.1 — комплектная гарнитура с кириллицей для новой нейтральной
типографики Korra. При наличии согласованного брендового шрифта используй его.

- [Inter Regular](Inter-Regular.ttf) — основной текст и спокойный заголовок.
- [Inter Medium](Inter-Medium.ttf) — умеренный акцент.
- [Inter SemiBold](Inter-SemiBold.ttf) — более сильная иерархия.

Файлы неизменённые из официального выпуска. Источник и контрольные суммы —
[SOURCE.json](SOURCE.json), условия распространения — [LICENSE.txt](LICENSE.txt).
При копировании гарнитуры сохраняй лицензию. Передавай приложению точный путь
от каталога этого навыка, не рассчитывай на системную установку или загрузку
из сети. Проверь имя загруженного шрифта, русские буквы, переносы и готовый
экспорт. Inter — самостоятельная гарнитура, не копия SF Pro.
