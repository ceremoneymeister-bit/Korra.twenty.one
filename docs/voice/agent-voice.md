# Голос агента

В кабинете: **Агенты → меню вкладки → Голос**. Каждый агент хранит своё
подключение, голос, скорость и режим ответа. По умолчанию функция выключена.

## Подключения

- **ElevenLabs:** свой API-ключ, ID голоса или явная загрузка списка голосов
  аккаунта. Multilingual v2 — вариант для выразительности, Flash v2.5 — для
  скорости. Качество и задержку проверяйте кнопкой «Проба голоса»; каждый
  запрос расходует лимит аккаунта.
- **Совместимый HTTP API:** отдельно установленный или облачный сервис.
  Адрес должен быть доступен серверу Korra, например
  `http://voice-server:8000/v1`. Korra отправляет `POST /audio/speech`
  относительно этого адреса, JSON с `input`, `model`, `voice`,
  `response_format: "mp3"` и необязательным `speed`. Ответ — аудиобайты,
  HTTP 200. Если задан ключ, передаётся `Authorization: Bearer …`.
  Иной протокол требует отдельного адаптера. VoiceStudio и модели
  автоматически не устанавливаются; их лицензии действуют отдельно.

Ключи записываются только в `.env` выбранного профиля:
`KORRA_VOICE_ELEVENLABS_KEY` или `KORRA_VOICE_HTTP_KEY`. API кабинета возвращает
только признак наличия ключа. Ключ другого агента или окружения процесса
не подхватывается. При ошибке другой сервис автоматически не вызывается.

## Поведение

В кабинете доступна кнопка «Послушать» и автоматическая озвучка новых ответов
в открытой вкладке. История сама не озвучивается. Браузер может потребовать
нажатия ▶ для включения звука. Аудио не сохраняется в истории между загрузками
страницы. Синтез завершается до воспроизведения; это не потоковый голосовой
разговор. Запрос кабинета ограничен 5000 символами, аудио — 25 МиБ;
одновременно обрабатывается до двух запросов кабинета.

В Telegram выбирается текст, голос в ответ на голосовое сообщение или текст
и голос на каждое сообщение. Прежняя команда `/voice off` отключает автоозвучку
для чата. Выключение голоса в кабинете отключает управляемую озвучку агента.
При сбое текст сохраняется. Совместимый сервис возвращает MP3; существующий
тракт TTS преобразует его для голосового сообщения Telegram через ffmpeg.

Настройки находятся в `voice.agent_voice` и `tts` профиля. Профили без
`voice.agent_voice` продолжают использовать прежнюю конфигурацию TTS.

## Проверка без расходов и сообщений людям

`tests/tools/test_tts_compatible.py` проходит настоящий локальный HTTP → TTS →
ffmpeg → Ogg/Opus. ElevenLabs проверяется по HTTP-контракту без обращения к
аккаунту. `tests/korra_cli/test_agent_voice.py` проверяет разделение профилей,
ключи, очистку файлов и Telegram-режимы. Эти проверки не подтверждают качество
реального голоса, задержку провайдера или доставку в живой Telegram.
