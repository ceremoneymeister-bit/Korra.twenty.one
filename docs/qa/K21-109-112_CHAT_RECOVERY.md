# K21-109–112: восстановление чата и понятные ошибки

17.09.2026. Локальный пакет поверх опубликованной 0.21.8
`58a8414d4d0dfa47e3bfae627d8f93d845adb90a`, ветка `k21/chat-recovery-20260917`.
Публикация, rollout и живая модельная приёмка не выполнялись.

## Изменение поведения

- Retry/discard получают конкретные session/message внутри профиля. Устаревшая
  кнопка не затрагивает новую запись. Переход в другой чат сначала открывает
  его, без POST с историей предыдущего разговора.
- Локальное сообщение сохраняется при foreground-загрузке истории, отсутствии
  run и при старом завершённом run предыдущего сообщения. Совпавшую реплику
  объединяем по ledger identity/history_count, не по одному сходству текста.
- Неизвестная доставка проверяется с прежним message ID. Подтверждённый отказ
  возвращается в поле для проверки и новой явной отправки. Не запускаем заново
  внешние действия автоматически; предупреждаем о возможном частичном результате.
  Сохраняем следующий черновик и вложения; при превышении лимита восстановление
  не стирает ни текущие файлы, ни исходную копию.
- Outbox принимает те же 30 вложений, что composer; прежняя проверка отклоняла
  целую запись уже при 6 файлах. Старая форма записей остаётся совместимой.
- Причины отказа различаются: исчерпанный объём, временный лимит запросов,
  просроченный доступ, недоступная модель, перегрузка, слишком длинный контекст,
  timeout, сеть, файлы. HTTP 429 сам по себе не означает окончание подписки.
  При неизвестной причине не предлагаем менять ключи или оплачивать API.
- Ошибка SSE не дублируется как ответ агента. Причина подтверждённого отказа
  остаётся после F5; раньше mount заменял её общей ошибкой доставки.
- Вместо постоянной строки «Сейчас в работе» — «Задачи: N» с раскрываемым списком
  конкретных чатов. Цитата явно подписана «Запрос», а не выдаётся за текущий этап.
  Сохранены очередь, несколько чатов агента, отметки готовности и stale status.
  Технические шаги свёрнуты по умолчанию, текущая операция видна в заголовке;
  явные запросы согласования остаются самостоятельными элементами.
- Во время ответа следующий черновик редактируется, Enter его не отправляет.
  Компактный textarea 40–120 px; длинный можно раскрыть до 320 px. Измерение
  высоты выполняется без CSS transition, поэтому очищенное поле сжимается.

## Границы и продолжение

- Это подтверждение общей ошибки и поведения пакета, не диагноз сетевого
  инцидента клиента. Нужна отдельная корреляция клиентских логов 17.09 04:31–04:37 UTC.
- Layout runs подставлены в read-only ответ браузера; браузерный recovery использует
  настоящий ledger. Ни тот ни другой тест не доказывает работоспособность подписки.
  Стенд не реализует health модели, поэтому боковой системный индикатор на части
  снимков сообщает недоступность; это ограничение стенда.
- Выбор темы проверяется через настоящий переключатель и его состояние в
  `layout.py`; ранний `browser.py` сохранял снимок с именем `recovery-dark`,
  не переключив тему. Этот ранний файл НЕ доказательство тёмной темы.
- Времени восстановления лимита нет в проверенном контракте: не обещаем конкретную
  минуту. Если появятся подтверждённые reset metadata, отдельно добавить время.
- Источник фоновой сессии, полное название/время обновления в списке активности
  требуют отдельного расширения metadata; не подменяем их догадкой по тексту.
- Следующий этап доставки: интеграция в будущий release, его обязательный CI и
  приёмка по release-процессу. Этот документ не разрешает публикацию или rollout.
