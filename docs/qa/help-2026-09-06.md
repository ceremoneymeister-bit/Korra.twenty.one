## Навигация и оформление

- Добавлен один общий маршрут `/help/:article`; изменение `App.tsx` сразу закоммичено отдельно. Другие общие компоненты не менялись.
- Все переходы внутри помощи и к разделам — `Link`/`useNavigate` общего роутера. Адреса картинок получаются через `useHref`. Имя клиента и корень домена в продукте не зашиты.
- Поиск учитывает заголовки, шаги, ошибки, ключевые слова, регистр и `ё/е`. Запрос живёт в адресе, сохраняется при возврате браузером. Есть очистка и понятный пустой результат.
- На большой ширине — боковое оглавление, на телефоне — выбор инструкции. В статье есть список шагов с якорями, возврат к оглавлению и связанные инструкции. Неизвестный адрес предлагает поиск.
- Шрифт Onest, поверхности и тени принятой палитры; лайм используется для заливки главного действия. При переходе к шагу устанавливаются прокрутка и фокус. Корректно обработана повреждённая ссылка с якорем.
- Иллюстрации раскрываются по желанию и загружаются отложенно. Кнопка «Увеличить снимок» открывает его в исходном размере с прокруткой; Escape закрывает просмотр и возвращает фокус кнопке.
- Контекстные кнопки «?» в остальных разделах оставлены их исполнителям: полноценная навигация доступна из существующего пункта «Помощь», дополнительных изменений чужих страниц для неё не требуется.
