# Синтетический стенд продуктового интерфейса

Поднимает настоящий `App` в `MemoryRouter` с подменённым `window.fetch`
(`demo-api.ts`) — без движка, без сети и без пользовательских данных.

```bash
cd engine/web
npx vite --config vite.interface.config.ts   # http://127.0.0.1:5184/
```

`?theme=dark` открывает тёмную тему. Режим оболочки стенд выставляет сам
(`__KORRA_UI_MODE__: "fleet"`).

## Проверки мобильной подачи

Оба скрипта работают по поднятому стенду, печатают измерения и возвращают
ненулевой код при нарушении проверяемого контракта. Нужен системный Python
с `playwright` (chromium уже установлен).

```bash
python3 prototypes/interface/mobile-audit.py    /tmp/korra-mobile-audit
python3 prototypes/interface/mobile-symptoms.py /tmp/korra-mobile-symptoms
```

- `mobile-audit.py` — обход `/dashboard`, `/agents`, `/files`, `/cron` на
  390 / 430 / 768 / 820 / 1024 / 1280 px: горизонтальное переполнение,
  размер шрифта видимых полей, цели меньше 44 px, цвет системного хрома.
  Складывает скриншоты и `report.json` в указанную папку.
- `mobile-symptoms.py` — сценарный прогон шести жалоб владельца от 21.09:
  уведомление о готовом ответе, прокрутка полосы вкладок пальцем, панель
  истории чатов, зум при фокусе в поле, прозрачность выдвижного меню,
  цвет хрома после смены темы.

Стенд заменяет браузерную приёмку только на Chromium. Поведение iOS Safari
(автозум, безопасные области, окраска хрома) проверяется на живом устройстве.
